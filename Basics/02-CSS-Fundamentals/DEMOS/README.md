# CSS Demos

This folder contains 5 progressive CSS demonstration files for teaching CSS Fundamentals and the Box Model.

---

## 📁 DEMO FILES INCLUDED

### **demo-01-css-basics.html**
**Purpose:** Introduction to CSS - three ways to add CSS  
**Concepts:** Inline, internal, external CSS; Basic syntax  
**When to use:** Beginning of session

### **demo-02-selectors.html**
**Purpose:** CSS selector types and specificity  
**Concepts:** Element, class, ID, descendant, multiple selectors  
**When to use:** After CSS basics

### **demo-03-box-model.html**
**Purpose:** Interactive Box Model demonstration  
**Concepts:** Content, padding, border, margin, box-sizing  
**When to use:** Main teaching section (most important!)

### **demo-04-typography.html**
**Purpose:** Text styling and readability  
**Concepts:** Fonts, sizes, colors, spacing  
**When to use:** CSS properties section

### **demo-05-colors.html**
**Purpose:** Color systems and palettes  
**Concepts:** Named, hex, RGB, RGBA, CSS variables  
**When to use:** Typography section or reference

---

## 🎓 INSTRUCTOR USAGE

**Teaching Progression:**
1. demo-01 → Show three methods
2. demo-02 → Type selectors live
3. demo-03 → Deep dive Box Model (spend most time)
4. demo-04 → Quick typography demo
5. demo-05 → Reference for colors

**Tips:**
- TYPE code live, don't just show
- Ask predictions before changes
- Use DevTools for every demo
- Make intentional mistakes, fix them

---

## 👨‍🎓 STUDENT USAGE

**During Class:** Code along, experiment, ask questions  
**After Class:** Reference for labs, modify to learn  
**Study:** Run in browser, change values, break and fix
