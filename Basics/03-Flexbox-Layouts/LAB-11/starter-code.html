Quick Flexbox Reference

Container Properties (on parent)

display: flex;                /* Enable flexbox */
justify-content: space-between; /* Horizontal: left ← → right */
justify-content: center;       /* Horizontal: center */
align-items: center;           /* Vertical: center */
flex-direction: column;        /* Stack vertically */
flex-wrap: wrap;               /* Allow wrapping */
gap: 1rem;                     /* Spacing between items */

Item Properties (on children)

flex: 1;            /* Take equal space */
flex: 0 0 200px;    /* Fixed 200px width */
flex: 1 1 250px;    /* Responsive: min 250px, can grow/shrink */

Common Patterns

Pattern CSS
Logo left, links right justify-content: space-between
Equal columns flex: 1 on all items
Fixed sidebar + flexible main flex: 0 0 200px + flex: 1
Responsive wrapping cards flex-wrap: wrap + flex: 1 1 250px

Common Issues:

  • ❌ Items not moving: Did you forget display: flex?
  • ❌ No spacing: Did you add gap?
  • ❌ Sidebar not fixed: Did you use flex: 0 0 200px?
  • ❌ Gallery not wrapping: Did you add flex-wrap: wrap?
  • ❌ Footer not at bottom: Did you add flex: 1 to content wrapper?
