# HTML5 Demos

Demo files for HTML5 semantic structure session.

---

## 📁 DEMO FILES INCLUDED

1. **demo-01-basic-structure.html** - Basic HTML5 document structure
2. **demo-02-semantic-vs-div.html** - Comparison of semantic HTML vs div soup
3. **demo-03-complete-page.html** - Complete portfolio page example (live coding demo)
4. **demo-04-accessibility.html** - Accessibility examples (good vs bad)
5. **demo-05-forms.html** - Accessible form patterns

---

## 🎯 HOW TO USE THESE DEMOS

### For Instructors:
- Use **demo-01** to introduce basic HTML structure
- Use **demo-02** to illustrate why semantic HTML matters
- Code **demo-03** live with students (don't show complete version first)
- Use **demo-04** to demonstrate accessibility checklist
- Use **demo-05** to show proper form structure

### For Students:
- Reference these examples when building your own pages
- Study the comments to understand why each element is used
- Try modifying the examples to experiment
- Use as templates for your projects

---

## 💡 TEACHING TIPS

**demo-01:** Start simple, explain each line
**demo-02:** Show both side-by-side, discuss differences
**demo-03:** Type this live! Don't just show completed version
**demo-04:** Use screen reader if available, or demonstrate Tab navigation
**demo-05:** Emphasize label/input connection
