# WEEK 03 - HTML5 & CSS Fundamentals

**Sprint:** Sprint 02 - Professional Portfolio Website (Week 1 of 2)  
**Focus:** HTML5 semantic structure, CSS fundamentals, Flexbox layouts, Responsive design

---

## 📅 WEEK OVERVIEW

### Learning Objectives
By the end of Week 3, students will be able to:
- Build semantic HTML5 page structures
- Apply CSS fundamentals (selectors, Box Model, typography)
- Create flexible layouts using Flexbox
- Implement responsive designs with media queries
- Understand mobile-first design principles
