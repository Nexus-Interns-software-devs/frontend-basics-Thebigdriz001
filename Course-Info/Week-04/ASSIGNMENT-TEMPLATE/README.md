## 🚀 GETTING STARTED

### Step 1: Accept the Assignment
1. Click the GitHub Classroom invitation link (provided in Discord)
2. Accept the assignment
3. GitHub will create your personal repository: `week-04-labs-tickets-YOUR-USERNAME`

### Step 2: Clone Your Repository
```bash
# Navigate to where you want to store your projects
cd Desktop/Bootcamp

# Clone your personal repo (replace YOUR-USERNAME)
git clone https://github.com/3LOGY-Bootcamp-2026/week-04-labs-tickets-YOUR-USERNAME.git

# Navigate into the folder
cd week-04-labs-tickets-YOUR-USERNAME
```

### Step 3: Complete the Assignments
For each lab/ticket:
1. **Read the instructions:** Open `LAB-XX/instructions.md` or `TICKET-XX/requirements.md`
2. **Write your code:** All code goes in the `code/` subfolder
3. **Test thoroughly:** Open your HTML file in multiple browsers
4. **Commit & push:**
   ```bash
   git add .
   git commit -m "Complete LAB-13: Interactive CSS Components"
   git push
   ```
5. **Check submission:** Review `submission.md` checklist before marking complete
