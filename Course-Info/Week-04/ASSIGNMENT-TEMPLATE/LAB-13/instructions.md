## 🎯 OVERVIEW

Build an interactive component library using:
- CSS positioning (absolute, relative, z-index)
- CSS transitions (smooth hover effects)
- CSS animations (keyframes, fadeIn, pulse)
- CSS transforms (scale, translate, rotate)

**Choose 3 components to build:**
- Animated button with hover effects
- Card flip animation
- Modal or dropdown with transitions
