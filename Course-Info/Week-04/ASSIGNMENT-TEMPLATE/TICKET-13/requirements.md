## 🎯 OBJECTIVE

Create an interactive product card component using advanced CSS:
- CSS positioning (absolute, relative, z-index)
- CSS transitions (smooth hover effects)
- CSS animations (fadeIn, pulse, etc.)
- CSS transforms (scale, translateY, rotate)

---

## 💡 KEY FEATURES

**Required Components:**
- Product image, title, description, price
- \"Add to Cart\" button
- Favorite icon (absolutely positioned top-right)
- Hover effects (card lifts, image scales)
- Fade-in animation on page load
- Pulse animation on price badge
