## 🎯 OBJECTIVE

Enhance Lab 15 to-do list with:
- Priority levels (Low, Medium, High)
- Filter system (All | Active | Completed)
- Sort functionality (By Priority | By Date)
- Live statistics dashboard

---

## 💡 ENHANCEMENT FEATURES

**1. Priority Levels:**
- Dropdown to select priority when adding task
- Color-coded visual indicators (green/yellow/red)
- High priority tasks show ⚠️ icon

**2. Filter & Sort:**
- Filter buttons: All | Active | Completed
- Sort dropdown: By Priority | By Date Added
- Count displays: \"Showing 3 of 5 tasks\"

**3. Statistics Dashboard:**
- Total tasks count
- Active tasks count
- Completed tasks count
- Completion percentage
- Updates in real-time
