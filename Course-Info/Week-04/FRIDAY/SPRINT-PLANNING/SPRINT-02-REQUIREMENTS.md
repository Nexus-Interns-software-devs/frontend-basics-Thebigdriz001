# Sprint 02: Professional Portfolio Website

**Duration:** Week 4 Friday → Week 6 Friday  
**Total Points:** 200  
**Presentations:** Week 6 Friday (10 min each)

---

## 🎯 PROJECT OVERVIEW

Build a professional portfolio website that showcases your projects, skills, and contact information. This will serve as your calling card to potential employers and demonstrates everything you've learned in Weeks 1-4.

---

## 📋 CONTENT REQUIREMENTS

### Required Pages (4 minimum)

1. **Home Page (`index.html`)**
   - Hero/banner section with your name and tagline
   - Brief introduction
   - Call-to-action buttons (View Projects, Contact Me)
   - Preview of featured projects

2. **About Page (`about.html`)**
   - Professional bio (2-3 paragraphs)
   - Profile photo
   - Skills & technologies list
   - Education / bootcamp journey
   - Fun facts or interests

3. **Projects Page (`projects.html`)**
   - Showcase 3+ bootcamp projects
   - Each project card includes: title, description, screenshot, technologies used
   - Links to GitHub repos and live demos
   - Card layout with hover effects

4. **Contact Page (`contact.html`)**
   - Contact form (Name, Email, Message — minimum fields)
   - Form validation (JavaScript)
   - Success/error messages
   - Social media / GitHub / LinkedIn links

---

## ⚙️ TECHNICAL REQUIREMENTS

### HTML (30 points)
- [ ] Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- [ ] Proper heading hierarchy (single `<h1>` per page)
- [ ] Accessible images (`alt` text on all images)
- [ ] Valid HTML (passes W3C Validator)
- [ ] Proper `<meta>` tags (charset, viewport, description)

### CSS (40 points)
- [ ] External stylesheet(s) — no inline styles
- [ ] CSS custom properties (variables) for colors and fonts
- [ ] Flexbox and/or Grid layouts
- [ ] Professional color scheme and typography
- [ ] Smooth transitions and hover effects
- [ ] Consistent spacing and alignment

### Responsive Design (30 points)
- [ ] Mobile-first approach
- [ ] Media queries for tablet (768px+) and desktop (1024px+)
- [ ] Works on screens from 320px to 1920px
- [ ] Responsive navigation (hamburger menu on mobile)
- [ ] Images scale properly

### JavaScript Interactivity (40 points)
Implement **3 or more** of the following:
- [ ] Mobile navigation toggle (hamburger menu)
- [ ] Smooth scrolling navigation
- [ ] Contact form validation
- [ ] Project filter/search
- [ ] Modal/lightbox for project details
- [ ] Back-to-top button
- [ ] Dark mode toggle (bonus)
- [ ] Scroll-triggered animations (bonus)

### Form Handling (included in JS points)
- [ ] Contact form with client-side validation
- [ ] Required field checking
- [ ] Email format validation
- [ ] User-friendly error messages
- [ ] Success confirmation
