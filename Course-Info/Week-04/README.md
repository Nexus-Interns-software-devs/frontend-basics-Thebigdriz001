## 🎯 SPRINT 02: PROFESSIONAL PORTFOLIO WEBSITE

### Project Overview
Build a professional portfolio website showcasing your projects, skills, and contact information.

### Requirements
- ✅ **4+ pages:** Home, About, Projects, Contact
- ✅ **Semantic HTML5:** Proper use of header, nav, main, section, article, footer
- ✅ **Responsive Design:** Mobile-first, works on all screen sizes
- ✅ **Flexbox/Grid Layouts:** Modern CSS layout techniques
- ✅ **JavaScript Interactivity:** 3+ interactive features
- ✅ **Form Validation:** Contact form with validation
- ✅ **Accessibility:** WCAG AA standards
- ✅ **Deployed:** Live on GitHub Pages or Netlify
- ✅ **Professional README:** Project documentation

### Timeline
- **Friday Week 4:** Planning, wireframes, repo setup
- **Monday Week 5:** HTML structure complete
- **Wednesday Week 5:** CSS styling complete
- **Friday Week 5:** JavaScript features complete
- **Monday Week 6:** Testing, polish, deployment
- **Friday Week 6:** Sprint 02 demo presentations
